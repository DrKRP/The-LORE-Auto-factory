# Baseline v0: TOF, before distractor-first

The first author tournament (24 variants: 8 segments × 3 techniques), written under the pre-redesign rules: misconceptions chosen by the architect, no trap brief, no branch analysis, no end-of-module report. All 24 passed the segment check of that time.

Kept as the "before" arm for efficacy comparisons with the distractor-first pipeline (see `../plan.md`). The variants use the old `misconception` choice kind, so the current validator will not accept them; compare them through blind judging only.
