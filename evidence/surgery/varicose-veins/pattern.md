# Exam pattern — Varicose veins (surgery)

Knowledge mode: asks recalled from model knowledge of NEET PG / INI-CET patterns. They steer coverage and the trap brief; they never support a fact.

## P1
- ask: Investigation of choice for varicose veins
- frequency: model knowledge
- exam_answer: Duplex ultrasound (colour Doppler)
- seen_at: model knowledge

## P2
- ask: Test for saphenofemoral junction incompetence vs test for deep vein patency
- frequency: model knowledge
- exam_answer: Brodie–Trendelenburg test (SFJ); Perthes test (deep veins)
- seen_at: model knowledge

## P3
- ask: Trendelenburg operation — what is done
- frequency: model knowledge
- exam_answer: Flush ligation of GSV at SFJ with ligation of tributaries
- seen_at: model knowledge

## P4
- ask: Treatment of choice for varicose veins with SFJ incompetence (older keys) / first-line current treatment
- frequency: model knowledge
- exam_answer: Older keys: Trendelenburg operation + stripping; current: endovenous thermal ablation (RFA/EVLA)
- seen_at: model knowledge

## P5
- ask: Nerve injured during GSV stripping / SSV surgery
- frequency: model knowledge
- exam_answer: Saphenous nerve (GSV); sural nerve (SSV)
- seen_at: model knowledge

## P6
- ask: Location of named perforators (Dodd, Boyd, Cockett, Hunter)
- frequency: model knowledge
- exam_answer: Dodd — lower thigh/Hunter's canal; Boyd — below knee; Cockett — medial ankle/lower leg; Hunter — mid-thigh
- seen_at: model knowledge

## P7
- ask: Most common site of venous ulcer
- frequency: model knowledge
- exam_answer: Gaiter area, above the medial malleolus
- seen_at: model knowledge

## P8
- ask: Sclerosant used in sclerotherapy of varicose veins
- frequency: model knowledge
- exam_answer: Sodium tetradecyl sulphate (polidocanol also accepted)
- seen_at: model knowledge

## P9
- ask: CEAP classification — what class is a healed ulcer / active ulcer / skin changes
- frequency: model knowledge
- exam_answer: C5 healed ulcer; C6 active ulcer; C4 skin changes
- seen_at: model knowledge

## P10
- ask: Contraindication to superficial venous surgery / stripping
- frequency: model knowledge
- exam_answer: Deep vein thrombosis / occluded deep veins (positive Perthes)
- seen_at: model knowledge

## P11
- ask: Saphena varix — features and differential
- frequency: model knowledge
- exam_answer: Compressible, cough impulse, fluid thrill, disappears on lying; differential femoral hernia
- seen_at: model knowledge

## P12
- ask: Malignancy arising in long-standing venous ulcer
- frequency: model knowledge
- exam_answer: Squamous cell carcinoma (Marjolin's ulcer)
- seen_at: model knowledge

## P13
- ask: Most common cause of recurrence after varicose vein surgery
- frequency: model knowledge
- exam_answer: Neovascularisation at the SFJ (also inadequate primary surgery)
- seen_at: model knowledge

## P14
- ask: Relation of GSV / SSV to malleoli; termination of each
- frequency: model knowledge
- exam_answer: GSV anterior to medial malleolus → femoral vein; SSV behind lateral malleolus → popliteal vein
- seen_at: model knowledge
