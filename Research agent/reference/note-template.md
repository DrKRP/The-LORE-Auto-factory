# Note template

Every note follows this skeleton in this order. Omit a core section that has no meaning for the topic (a drug topic has no "Clinical features"); never pad one.

- Every factual sentence ends in a citation marker `[n]`; `[n]` numbers sources in the References list, in order of first use.
- Tag a claim that failed verification and could not be rescued with ` ⚠ Unverified` after its marker.
- Write for a final-year MBBS student revising for NEET PG: dense, plain, bullet-first, no filler. Bold the word the exam would test.

```markdown
---
topic: <Topic name>
subject: <subject-slug>
exam: NEET PG / INI-CET
researched: <YYYY-MM-DD>
claims_verified: <n>
claims_unverified: <n>
---

# <Topic name>
```
