# Trap brief: Inguinal hernia

Built from `evidence/surgery/inguinal-hernia/pattern.md` (P1–P13), the note's ⚠ Exam notes (K107–K112), the "Most common / Investigation of choice / Drug of choice" table (K93–K106), and model-knowledge wrong models. No recall sources were supplied, so `frequency` is pattern or model knowledge only. Every entry has one primary error type.

## TR1
- trap: Direct and indirect hernias swapped relative to the inferior epigastric vessels
- wrong_answer: "Indirect hernia passes medial to the inferior epigastric vessels" (or direct lateral)
- where: P2 stems; "which hernia lies lateral to the inferior epigastric vessels"; deep-ring vignettes
- error_type: E3
- why_tempting: "direct" sounds like "straight in front of the pubic tubercle", so the learner assigns direct the lateral position
- frequency: P2; model knowledge
- refuted_by: K3, K12, K13
- yield: high
